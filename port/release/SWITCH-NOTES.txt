Downhill Switch 0.1.0-beta.1
============================

Downhill Domination running natively on the Nintendo Switch, as homebrew. It is the Switch
port of Downhill Revived (https://github.com/skuza-oss/downhill-revived), the project that
decompiled the game and made it portable; this build runs that same game core.

It needs a Switch that can run homebrew (Atmosphere). It is not a Nintendo product, and it
contains none of the game: you bring your own disc image.

This is a beta: see "Known problems" before you play.


What you need
-------------

* A Switch running Atmosphere, with the Homebrew Menu.
* Your own dump of a Downhill Domination (USA) disc, as an .iso file.


Installing
----------

1. Copy the whole switch/ folder of this archive onto your SD card, so that you have
   sdmc:/switch/downhill-switch/dhd.nro
2. Put your disc image beside it as game.iso, or name it in dhd.ini (the iso = line).
3. Start the Homebrew Menu HOLDING R while you launch a game you own, not from the
   Album. Then pick Downhill Switch.

The last step matters. Started from the Album, homebrew gets a few hundred megabytes,
and the game needs far more; it will tell you so on screen and exit.


Settings
--------

dhd.ini, beside dhd.nro, has the settings and explains each one. The ones that change
the most:

  scale = 1   the PlayStation 2's own resolution: the smoothest races.
  scale = 2   twice as sharp. Races run at about 44 frames a second.

  DHD_SWITCH_CLOCKS = on   raises the CPU, GPU and memory clocks to the rates Horizon
                           uses for its own boost modes. The game needs them. "max"
                           goes a step further and runs hotter; "off" leaves the
                           clocks alone, which is what to use if sys-clk manages this
                           title, so the two do not fight.

  DHD_ASPECT = 16:9 and widescreen = 1   fill the screen. Loading screens and other
                           pictures drawn for 4:3 stay 4:3, with the sides filled.

The game also has its own SETTINGS page in the menus.

Raised clocks mean a warmer console and a shorter battery in handheld. That is the
trade for a playable rate on this hardware.


What works
----------

The game and its menus, the opening movies, sound, the pads, memory cards (saves go in a
saves/ folder beside dhd.nro), rumble, and EXIT GAME back to the Homebrew Menu, from which
the game can be started again.


Known problems
--------------

* Your rider's shadow has been seen flat (one plain colour) for part of a race, then
  back to normal. It does not happen every time.
* Races do not reach 60 frames a second: the Switch's three cores are nearly full.
  The first fields after a race starts can stutter while the track loads.
* Online play is off on the Switch, as it is on phones.

There is no update check and no launcher: to update, replace dhd.nro.


Where the files go
------------------

  sdmc:/switch/downhill-switch/dhd.nro     the game
  sdmc:/switch/downhill-switch/dhd.ini     your settings
  sdmc:/switch/downhill-switch/game.iso    your disc image
  sdmc:/switch/downhill-switch/dhd.log     what the last run logged
  sdmc:/switch/downhill-switch/saves/      memory cards

Moving from an earlier test build in another folder? Copy its saves/ folder here to keep
your progress.

If something goes wrong, dhd.log beside the .nro says what happened, and it is the
thing to attach to a report. A crash also leaves a report in sdmc:/atmosphere/crash_reports/.
Reports go to the issues of https://github.com/RonyAbreu/downhill-switch
